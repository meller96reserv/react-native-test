# Сценарий скринкаста

Цель — за 5–8 минут показать не только результат, но и рабочий цикл «разработчик + AI».

1. Открыть `todo.txt`, затем кратко показать созданные AI `AGENTS.md`, архитектуру и чек-лист.
2. Показать пример генерации: попросить AI объяснить session reducer или создать тест для parser.
3. Показать рефакторинг: попросить AI оценить границы контекстов и лишние ререндеры; открыть
   разделение `SessionStateContext` / `SessionActionsContext` и memoized `PlanCard`.
4. Показать поиск ошибки: запустить `npm run typecheck`, `npm run lint` и тесты, затем попросить AI
   разобрать вывод. В истории разработки уже был найден конфликт версий Expo tooling.
5. Запустить приложение с очищенными данными и пройти onboarding → выбор месяца/года → покупка.
6. Полностью закрыть приложение и открыть снова: первым содержательным экраном должен быть home.
7. Показать README: архитектуру, структуру и список production-улучшений.
8. Перед публикацией скрыть уведомления, секреты, личные пути и лишние окна.

Проверочный кадр должен явно показать, что «Тестовая покупка» не производит реального списания.
